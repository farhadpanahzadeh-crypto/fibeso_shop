# Product photos

Drop real product photos here, named by product id (see `assets/js/data/products.js`):

- `l01.webp`, `u03.jpg`, `n02.png` ...
- square, white or very light background, about 1000 x 1000 px, WebP preferred

Then run `python3 scripts/import-photos.py`. Products without a photo keep their SVG drawing.
