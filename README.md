# فروشگاه فیبسو — Fibeso Shop (front-end)

Static, RTL Persian storefront for Fibeso: network equipment, new and used (graded)
laptops, and new/used laptop parts. Plain HTML, CSS and vanilla JavaScript — no
framework and no build step is needed to run it.

## Run locally

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

(Opening `index.html` directly also works; a local server is closer to production.)

## Pages

| Page | File |
|---|---|
| Home | `index.html` |
| Shop / category / search (URL filters: `cat`, `sub`, `condition`, `grade`, `brand`, `q`, `min`, `max`, `tag`, `sort`) | `pages/shop.html` |
| Product detail (`?id=`) | `pages/product.html` |
| Cart | `pages/cart.html` |
| Checkout (requires sign-in) | `pages/checkout.html` |
| Sign in / sign up (mobile + one-time code) | `pages/login.html` |
| User panel: dashboard, orders, wishlist, addresses, profile (`#orders` etc.) | `pages/account.html` |
| B2B / corporate purchase + quote form | `pages/b2b.html` |
| About, Contact, FAQ, Warranty & grading | `pages/about.html`, `contact.html`, `faq.html`, `warranty.html` |
| Blog list and article (`?slug=`) | `pages/blog.html`, `pages/post.html` |
| Not found | `404.html` |

## Editing pages

Header and footer are shared partials. Pages are generated from templates:

```
templates/partials/header.html, footer.html
templates/pages/*.html        # JSON front matter + page body
python3 scripts/build-pages.py   # writes index.html, 404.html and pages/*.html
```

The generated HTML is committed, so the site runs without running the script.

## Structure

```
assets/css/tokens.css        # brand palette + design tokens (change colors here only)
assets/css/base.css, layout.css, components.css
assets/css/pages/*.css       # page-specific styles
assets/js/data/products.js   # sample catalogue (replace with real data)
assets/js/data/posts.js      # sample blog posts
assets/js/shop.js            # catalogue queries, product cards, cart, wishlist, toasts
assets/js/store.js           # account, addresses, orders, form validation
assets/js/navigation.js      # header, mobile menu, category mega menu
assets/js/pages/*.js         # page scripts
assets/images/               # SVG art generated by scripts/generate-images.py
```

## Prototype limitations

- There is no backend: cart, wishlist, account, addresses and orders are stored in the
  browser (`localStorage`). No SMS is sent (demo code `12345`), no payment is taken,
  and contact/B2B/review forms are validated but not sent. Each of these says so on screen.
- Products, prices, ratings and stats are sample data; product images are SVG drawings.
