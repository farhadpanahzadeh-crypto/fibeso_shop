# site-capture

ابزاری که آدرس یک سایت را می‌گیرد، صفحه‌هایش را پیدا می‌کند و از **هر نوع صفحه** نسخه
**دسکتاپ (۱۴۴۰ پیکسل)** و **موبایل (۳۹۰ پیکسل)** را تمام‌صفحه عکس می‌گیرد و در پوشه
`captures/` کنار خود ابزار ذخیره می‌کند. بعد آن پوشه را پوش می‌کنید تا از روی عکس‌ها
سایت ساخته شود.

رابط کاربری با React است. عکس‌برداری را یک سرور کوچک Node با Playwright (مرورگر Chromium)
انجام می‌دهد؛ چون یک صفحه وب به تنهایی نمی‌تواند از سایت دیگری عکس بگیرد.

## نصب (فقط بار اول)

پیش‌نیاز: [Node.js](https://nodejs.org) نسخه ۱۸ یا بالاتر.

```bash
cd tools/site-capture
npm run setup        # نصب وابستگی‌ها + دانلود مرورگر Chromium
```

## اجرا با رابط گرافیکی

```bash
npm run dev
```

مرورگر خودکار روی `http://localhost:5173` باز می‌شود. آدرس سایت را بدهید و «شروع» را بزنید.
پیشرفت کار و پیش‌نمایش عکس‌ها زنده نمایش داده می‌شود.

## اجرا از خط فرمان (بدون رابط)

```bash
npm run capture -- https://www.technolife.com --max 60 --per-pattern 2
```

| گزینه | کار |
|---|---|
| `--max 40` | حداکثر تعداد صفحه |
| `--per-pattern 2` | از هر نوع صفحه چند نمونه (مثلاً فقط ۲ صفحه محصول، نه هزاران) |
| `--depth 4` | حداکثر عمق دنبال‌کردن لینک‌ها |
| `--desktop-only` / `--mobile-only` | فقط یک نما |
| `--png` | PNG به‌جای JPG (حجم بیشتر) |
| `--slice 2000` | ارتفاع هر تکه عکس |
| `--keep-query` | آدرس‌های دارای `?` را صفحه جدا حساب کن |
| `--login` | یک مرورگر باز می‌شود، دستی وارد حساب شوید و پنجره را ببندید |
| `--auth` | با ورود ذخیره‌شده عکس بگیر (برای پنل کاربری) |

## خروجی

```
captures/www.example.com/
  manifest.json                 فهرست صفحه‌ها، نوع هر صفحه، عنوان‌ها و بخش‌ها
  pages/001-home/
    desktop-full.jpg            کل صفحه در یک عکس (اگر خیلی بلند نباشد)
    desktop-part01.jpg ...      تکه‌های ۲۰۰۰ پیکسلی از بالا به پایین
    mobile-full.jpg
    mobile-part01.jpg ...
    page.html                   HTML صفحه برای بررسی ساختار
```

## نکته‌ها

- ابزار فقط لینک‌های همان دامنه را دنبال می‌کند و بین صفحه‌ها مکث می‌کند تا به سایت فشار نیاید.
- صفحه‌هایی که فقط با ورود دیده می‌شوند (پنل کاربری، سفارش‌ها): اول `--login` (یا دکمه
  «ورود دستی» در رابط)، بعد با `--auth` (یا تیک «با حساب واردشده») اجرا کنید.
  فایل `auth.json` شامل نشست ورود شماست و در گیت نادیده گرفته می‌شود؛ آن را پوش نکنید.
- حالت‌های تعاملی مثل مگامنوی باز را ابزار خودکار نمی‌گیرد؛ اگر لازم است، دستی اسکرین‌شات
  بگیرید و کنار بقیه در همان پوشه بگذارید.
- این عکس‌ها فقط مرجع چیدمان و ساختارند؛ متن، عکس و لوگوی سایت مرجع در سایت فیبسو کپی نمی‌شود.
