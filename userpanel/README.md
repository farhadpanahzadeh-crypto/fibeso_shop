# پیش‌نمایش پنل کاربری فیبسو

هر فایل این پوشه یک بخش از پنل کاربری است و بدون ورود باز می‌شود (با داده نمونه).
کافی است فایل را در مرورگر باز کنید؛ منوی کنار صفحه بین بخش‌ها جابه‌جا می‌کند.

| فایل | بخش |
| --- | --- |
| index.html | پیشخوان (در موبایل: منوی حساب) |
| orders.html | سفارش‌های من |
| wishlist.html | کالاهای مورد علاقه |
| comments.html | نظرات |
| addresses.html | نشانی‌ها |
| messages.html | پیام‌ها |
| recent.html | آخرین کالاهای دیده شده |
| profile.html | مشخصات فردی و حقوقی |
| wallet.html | کیف پول |

- داده‌های نمونه جدا از حساب واقعی ذخیره می‌شوند و به سایت اصلی کاری ندارند.
- این فایل‌ها با `python3 scripts/build-pages.py` از `templates/pages/account.html` ساخته می‌شوند؛
  برای تغییر طراحی، همان قالب و `assets/css/pages/account.css` را ویرایش کنید.
- پنل اصلی سایت همچنان `pages/account.html` است و ورود لازم دارد.
