## HAPEEC brand (هپییک · Motorcycle Platform)

The user's HAPEEC brand book, logo and final web palette are stored in
`docs/brand/HAPEEC.md` (with the source PDF and images beside it). Read it before
any HAPEEC design or front-end work.

Web palette (overrides the PDF):
- `#0D1C31` Midnight Navy: body text, headings, header, footer
- `#EC6A14` Throttle Orange: primary button, CTA, needle, key icons (text on it is navy, never white)
- `#FFFFFF` White: page and card background
- `#F3F5F8` Light Gray: alternating sections, dividers
- `#6B6B6B` Steel Gray: secondary text
- `#C2530A` Dark Orange: text links / orange on light backgrounds, only when needed
